\section{Introduction}

All three cameras at the NSF-DOE Vera C.\ Rubin Observatory, (LSSTCam \citep{10.71929/rubin/2571927}, LATISS \citep{10.71929/rubin/2571930}, and LSSTComCam \citep{10.71929/rubin/2561361}) write FITS output files in the same structure with some minor variations in the FITS headers indicating different software versions and capabilities.

\citeds{LCA-10140} and \citeds{LCA-13501} define the file format used for the test stand at SLAC and \citeds{LSE-400} describes an example header that was used early in the construction project.
This document describes the delivered system and any evolution of the format that happens during the observatory lifetime.

\section{Structure}

The basic layout of a Rubin camera FITS file is shown in Fig.~\ref{fig:layout}.
There is a primary header, with no data, containing the FITS headers for this observation.
Then there are 16 HDUs, named \texttt{SegmentNN}, with the data from each amplifier along with headers specific to that amplifier.
The data values are 32-bit integers compressed using the Rice compression algorithm \citep{2012arXiv1201.1336W}.
There are then two extensions describing the condition of the readout electronics board (\texttt{REB\_COND}) and checksums calculated from the camera configuration (\texttt{CONFIG\_COND}).
The final two extensions contain the measured position of the shutter when it opens and the shutter when it closes.

\section{Version Changes}
\label{app:headver}

When the FITS header schema or file layout is changed in any way there is a corresponding increment to the value stored in the \texttt{HEADVER} FITS card.

Errors in the contents of specific FITS headers are not documented here but are instead handled by the \texttt{astro\_metadata\_translator} package \footnote{\url{https://astro-metadata-translator.lsst.io/}} in conjunction with the \texttt{obs\_lsst} package that are both part of the LSST Science Pipelines \citedsp{PSTN-019}.
In particular, if you are not using the LSST Science Pipelines to read the raw data via the Data Butler \citep{2022SPIE12189E..11J}, some headers are likely to be incorrect or missing if you do not manually run the \texttt{astro\_metadata\_translator.fix\_header()} function on the primary header.

Note that LSSTCam and LATISS change header versions independently.

\subsection{Version 2}

This was the version of the header used for commissioning and pre-operations.
Data Preview 1 \citedsp{RTN-095} and most of Data Preview 2 will use this header version.

\subsection{Version 100}

Version 100 first appeared for LSSTCam in observation 20251017\#22.
All observations taken during observatory formal operations will have at least this version.

\begin{itemize}
\item The \texttt{DATE} header is now correctly being reported in UTC timescale, conforming with the FITS standard \citep{2010A&A...524A..42P}.
\item Added \texttt{TELAPSE} header corresponding to the elapsed exposure time.
      This corresponds to the total integration time and is identical to the existing \texttt{DARKTIME} header value.
      This header should be used in preference since it is formally part of the FITS standard 4.0 \citep{FITS4}.
\item Added \texttt{XPOSURE} header corresponding to the effective exposure duration.
      This is the same as \texttt{SHUTTIME} when the shutter was opened or \texttt{EXPTIME} when the shutter was not opened.
      This header should be used in preference to those other headers when determining the effective exposure time since it is formally part of the FITS standard 4.0 \citep{FITS4}.
\end{itemize}

\subsection{Version 101}

Version 101 first appeared for LSSTCam in observation 20251029\#1.

\begin{itemize}
  \item Added \texttt{HIERARCH SHUTTER} headers to the primary header providing fit parameters for the shutter closing and opening.
  \item Added two additional HDUs named \texttt{OPEN} and \texttt{CLOSE} containing the profile fits and shutter measurements.
  The shutter measurements are found in the binary tables.
\end{itemize}

\subsection{Version 102}

Version 102 first appeared for LSSTCam in observation 20251209\#8.

\begin{itemize}
  \item Added \texttt{SEQCLOCK} header to indicate the clock period of the REB/sequencer.
\end{itemize}
